# Commands

`/gopaint` has the alias `/gp`. Every subcommand needs `bettergopaint.use`.

| Command | Does | Extra permission |
|---|---|---|
| `/gopaint` | Lists the subcommands. | — |
| `/gopaint size <number>` | Sets your brush size. Values above `generic.max-size` are capped. | — |
| `/gopaint toggle` | Enables or disables your brush. | — |
| `/gopaint info` | Shows the plugin credits. | — |
| `/gopaint reload` | Re-reads `config.yml`. | `bettergopaint.admin` |

All commands are player-only.
