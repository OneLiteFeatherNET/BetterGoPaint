# Report a bug

1. Reproduce the problem on a supported version; see [Supported versions](../reference/supported-versions.md).
2. Upload your full `logs/latest.log` to [mclo.gs](https://mclo.gs).
3. Run these in the console and copy the output:

   ```
   version
   version BetterGoPaint
   version FastAsyncWorldEdit
   fawe debugpaste
   ```

4. Note which brush and which settings were in use: size, mask, surface mode, palette.
5. Open a [bug report](https://github.com/OneLiteFeatherNET/BetterGoPaint/issues/new/choose) and
   fill in every field with what you collected.
